Skapa en liten uppsättning med Skills som hjälper er att följa ett bra workflow för era projekt (programmering o dyl). Exempel på saker en typisk process kan innehålla:
gå från brainstorming till samsyn mellan man/machine till specifikation (t.ex. grill-me)
Något kring hur tickets kopplas till git commits, jira, etc. Hur tickets ska skrivas med tydliga och testbara mål, etc.
Något kring hur agenten ska bete sig när den tycker att den är klar med en ticket (review, test, test-coverage, integration, pull requests, ticket-uppdatering, etc)
handover, compaction, dokumentations-ordning
Kommunikation mellan parallella agenter (om applicerbart, överkurs!)
Skills för tankesätt (t.ex: "dual_pass"≈"confirmational->adversarial->concluding")
Skills för olika specialområden (t.ex. GUI-design, era preferenser för X Y Z, ...)
Skills för att använda infrastruktur som test-miljöer, servrar, virtuella maskiner, kubernetes-kluster, eller vad ni nu kan tänkas vilja att agenterna använder i olika situationer
Skill för att sammanfatta innehållet i hela er chat-session strukturerat i ett snyggt träd, så att det sedan går enkelt att hitta i transcript för den chatten (för andra agenter som kanske vill förstå bakgrunden till något)
Skills för er lokala knowledge-base. Se till att ni själva äger er domänkunskap, även om den är i form av agent-skrivna insikter för agenter.
